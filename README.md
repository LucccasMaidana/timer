# ActivePause ⏱️🏃

Aplicación Android para intercalar bloques de concentración y estudio con pausas activas de ejercicio y estiramiento.

## Características Nativas Android
- 📳 **Vibración de hardware nativa** en alarmas y pruebas.
- 📱 **Servicio en primer plano (Foreground Service)** con temporizador continuo en la barra de notificaciones mientras usas Instagram, WhatsApp o tienes la pantalla bloqueada.
- 🔔 **Pantalla de alarma superpuesta (*Full-screen intent*)** tipo reloj despertador que enciende la pantalla y muestra sugerencias de ejercicio con 1 solo toque para pausar o continuar.
- 🎨 **Diseño en tonos azulados modernos** con soporte para Modo Oscuro y Modo Claro.
- ⚙️ **Bloques y descansos personalizables de antemano:** presets de 25m, 45m, 50m, 60m, 90m (o minutos personalizados) y descansos libres o con tiempo.

## Compilación Automática
Este repositorio compila el `.apk` automáticamente en cada push mediante **GitHub Actions**. Puedes descargar el instalador listo en la sección [Releases](../../releases) o [Actions](../../actions).
